# AI Models

This directory contains the AI model weights required to run the application.

Please run the `download_models.py` script from the project root to fetch the public models (YOLO and TrOCR).

For the custom trained models, please follow the script instructions or manually place them as follows:
- VideoMAE model: `models/_weights/checkpoint-best.pth`
- YOLO Plate Detector: `models/_weights/plate_detector/best_Koushim_Model.pt`
